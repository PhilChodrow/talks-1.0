How do we learn the kernel from data?



Easiest case: for each \(i\) there is only one neighbor \(j\).

\[ \begin{aligned} x_i(t+1) - x_i(t) &= k(|d|) + \text{noise}\\ d &= x_j(t) - x_i(t) \end{aligned} \]


Adams, White, and Araujo (2022). “Person-to-person opinion dynamics: An empirical study using an online game.” PLoS ONE.

A more complex case: multiple neighbors


\[ \begin{aligned} \delta_i &\approx \frac{1}{|\partial i|} \sum_{j \in \partial i} k(d_{ij}) \;?\\ \delta_i &\approx k\left( \frac{1}{|\partial i|} \sum_{j \in \partial i} d_{ij} \right) \;? \end{aligned} \]


Vande Kerckhove + al. (2016). “Modelling Influence and Opinion Evolution in Online Collective Behaviour.” PLoS ONE.

Some common implicit assumptions




At each timestep
each agent always interacts
with all of their neighbors.


\[ \begin{aligned} \delta_i &\approx \frac{1}{|\partial i|} \sum_{j \in \partial i} k(d_{ij}) \;? \quad \delta_i \approx k\left( \frac{1}{|\partial i|} \sum_{j \in \partial i} d_{ij} \right) \;? \end{aligned} \]

Core idea for today: selective attention



At each timestep
each agent always sometimes interacts
with all some of their neighbors.

The reason this is empirically challenging is that we typically don’t observe these attentional mechanisms: we only observe the opinion changes that result.

Learning the model


Our stochastic model defines a likelihood function over observed opinion trajectories.

We learn the kernel parameters by maximizing this likelihood via the expectation-maximization (EM) algorithm (Dempster et al., 1977).

We select between competing models (kernels, mechanisms, etc.) by evaluating their predictive likelihoods on held-out validation data.

How the right-hand numbers are computed (drawn by panels/capability_ladder.py from figure_data/capability_ladder_dg_rff.json; same 15 rows as the paper figure, takacs_disliking_interior dropped):

  • A step’s value is deviance per transition, so its log likelihood ratio is value / 2 and its “% more” is exp(value / 2) - 1: the factor by which that step multiplies the per-update held-out likelihood.
  • “Selected on” = step value above selection.TIE_NATS (1e-3) out of the panels where the step exists; raw held-out comparison, no test. Selection exists only on the 8 networked panels.
  • “On average” = geometric mean over the panels where it is selected: exp(mean(value) / 2) - 1. Arithmetic means are dragged by CMV (retention alone is x3.2 there): 26% / 29% / 10%. Medians: tail 25%, retention 5%, selection 2%.
